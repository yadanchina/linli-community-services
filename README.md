# 邻里办 · 社区便民服务

纯前端社区服务原型，包含投诉、政策、零工就业和商铺服务页面。四类数据均为模拟数据，支持新增、编辑、删除，并保存在当前浏览器的 `localStorage` 中。

数据只保存在当前设备和浏览器，不会同步给其他用户或设备；清除浏览器站点数据会重置本地内容。

## 在线访问

GitHub Pages: https://yadanchina.github.io/linli-community-services/

## 本地预览

直接打开 `index.html` 即可。提交到 `main` 分支后，GitHub Actions 会自动发布 `dist/` 目录。
